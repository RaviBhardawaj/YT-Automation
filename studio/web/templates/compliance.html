Import market data

This app never downloads NSE or NSE Indices data automatically: both sites' terms prohibit automated collection and republication without permission. Download the official historical CSV yourself (e.g. niftyindices.com → Reports → Historical Data → NIFTY 50) or export it from a licensed vendor, then import it here. Every import records who, when, from where, and stores an immutable copy with its SHA-256.
